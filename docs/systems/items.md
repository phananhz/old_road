# Items

- Version: 0.2
- Status: Draft
- Last updated: 2026-08-14
- Purpose: Define static item data and stable identity.

Item definitions are ScriptableObjects with stable item IDs, display names, and stack metadata. Runtime quantities belong to `InventoryRuntime`, never to shared item definition assets.

Prototype item IDs:

- `item.wood`
- `item.stone`
- `item.cabin-plank`
- `item.wild-berries`
- `item.medicinal-herb`
- `item.mushroom`
- `item.iron-ore`
- `item.old-coin`
